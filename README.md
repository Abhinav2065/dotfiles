# dotfiles

Personal dotfiles for Arch Linux / Garuda with Hyprland.

## 🖥️ Components
- **Compositor**: Hyprland
- **Status Bar**: Waybar
- **Terminal**: Kitty / Alacritty
- **Shell**: Fish
- **App Launcher**: Rofi / Wofi
- **Widgets & Shell**: AGS (Aylur's GTK Shell)
- **Notifications**: SwayNC / Mako
- **System Monitor**: Btop
- **Audio Visualizer**: Cava
- **Screenshot Tool**: Swappy

## 🚀 Setup

Clone the repository:
```bash
git clone git@github.com:Abhinav2065/dotfiles.git ~/dotfiles
```

To sync configs to `~/.config/`:
```bash
cp -r ~/dotfiles/.config/* ~/.config/
```
